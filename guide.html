GUIDE DE DÉMARRAGE

Votre premier
multiview vMix.

Le site fournit les outils. vMix fournit les vidéos. Le compagnon local relie la configuration à vos écrans, même si Chrome et vMix utilisent des navigateurs différents.

1. Installer le compagnon sur le PC vMix

  1. Installez Node.js 22 ou ultérieur depuis le site officiel, si nécessaire.
  2. Téléchargez OpenMultiview puis extrayez le ZIP dans un dossier de votre choix.
  3. Double-cliquez sur start-openmultiview.cmd. Gardez la fenêtre ouverte pendant l’utilisation.

Vous pouvez aussi ouvrir un terminal dans le dossier et lancer :

node server.js

Le compagnon écoute uniquement sur votre PC, à l’adresse http://127.0.0.1:8090/config.html. Les sauvegardes sont conservées dans %LOCALAPPDATA%/multiview-vmix. Gardez ce dossier lors d’une mise à jour.

Vous pouvez configurer depuis le site officiel ou depuis les pages locales. Si votre navigateur demande l’accès au réseau local, autorisez-le pour connecter OpenMultiview à votre vMix. En cas de blocage, utilisez directement la configuration locale.

2. Vérifier la connexion vMix

Dans vMix, l’adresse et le port du Web Controller sont indiqués dans Settings → Web Controller. Sur le même PC, l’API utilise habituellement http://127.0.0.1:8088/api. Elle doit être accessible au navigateur et au compagnon.

Dans l’onglet Connexion, choisissez l’identifiant de votre PC, l’adresse de vMix, le port et le nombre d’écrans. Un écran correspond à une page web séparée. Le bandeau Synchronisation locale active confirme que le compagnon est détecté.

La construction automatique des layers demande vMix 27 ou ultérieur. Consultez aussi le guide officiel du Web Controller vMix.

3. Choisir les sources et la disposition

Dans Disposition, sélectionnez un preset et ajustez l’espacement. Vous pouvez choisir les sources à utiliser, ou laisser l’affectation automatique. Les écrans et les vignettes restent en 16:9.

OpenMultiview crée et réutilise les entrées vMix nécessaires. Quand un écran demande plus de neuf vidéos, plusieurs entrées de regroupement composent ses vues. Les IDs existants sont conservés.

Le layer 10 de l’entrée principale de chaque écran est réservé à sa source HTML. Il porte l’habillage, au-dessus des vidéos. Les groupes vidéo peuvent utiliser leurs dix layers.

4. Régler l’habillage

L’onglet Sources & layers permet d’affecter une source, de désactiver une vignette et de régler son texte, son cadre, son tally et ses vumètres. Placez le texte sur l’image, au-dessus ou en dessous ; l’audio peut être dans la vignette ou à côté.

Pour une liste vidéo, activez Décompte vidéo / infos liste : le titre, le temps écoulé, le temps restant et la boucle suivent le média, y compris sur OUTPUT ou un Mix. Un OUTPUT utilise le Master pour son audio, sauf si son nom désigne un BUS A à BUS G.

5. Retrouver les écrans au prochain live

Enregistrez le preset dans vMix pour conserver les inputs, leurs IDs et les positions vidéo. Dans OpenMultiview, mémorisez un modèle personnalisé et conservez les liens de Sauvegarde & URL.

Les anciens paramètres Inputs, Settings et MaskSettings restent acceptés. Sur un hébergement purement statique, les URL complètes rappellent la configuration d’un écran ; le compagnon est nécessaire pour le contrôle en direct entre Chrome et vMix.

Pour les configurations volumineuses, les réglages sont placés après # dans le lien : le serveur reçoit une adresse courte, et le navigateur retrouve tous les réglages. Copiez le lien entier, y compris cette partie. Avec le compagnon actif, les sources HTML créées automatiquement utilisent un lien court lié au PC et à l’écran.

Si un écran ne se connecte pas

  • Vérifiez que vMix et le compagnon sont ouverts.
  • Utilisez le même identifiant de PC dans la configuration et l’affichage.
  • Vérifiez la source HTML au layer 10 et utilisez Actualiser dans vMix après une mise à jour.
  • Si une page HTTPS ne joint pas l’API locale, utilisez les pages locales du compagnon. Les restrictions dépendent du navigateur intégré à vMix et de sa version.

Pour aller plus loin, consultez la documentation complète ou signalez un problème. Retirez les informations privées de vos captures et URL avant de les publier.
